# 100 oyoqli robot

Sichqoncha (yoki barmoq) harakatiga ergashib yuradigan, 100 oyoqli
animatsion robot. To'liq HTML + CSS + JavaScript, hech qanday
o'rnatish yoki server kerak emas.

## Ishga tushirish

`index.html` faylini ikki marta bosing — u to'g'ridan-to'g'ri
brauzeringizda ochiladi. Internet ham, Python ham, Django ham kerak
emas — bu mustaqil, o'zi ishlaydigan fayl.

## Boshqarish

- Sichqonchani harakatlantiring -> robot orqangizdan yuradi
- Pastki chap burchakdagi "🎨 Fonni almashtirish" tugmasi -> ikki xil
  fon (tungi koinot / quyosh botishi) orasida almashtiradi
